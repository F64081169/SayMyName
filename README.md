# Shannon's World

**GTA × The Sims × Friends：台灣新竹互動式人生模擬器**
第一季《我們還有地方可以坐嗎？》・七天試播集（可重玩的垂直切片）

> 不要只讓玩家生活在世界裡；要讓整個世界記得玩家曾經怎麼生活。

**第一人稱 3D**（Three.js）。支援 iPhone Safari（直向／橫向）與電腦瀏覽器，不需安裝、不需伺服器邏輯，遊戲自動存在瀏覽器的 localStorage。

## 怎麼玩

- 直接開 `index.html`（或用任何靜態伺服器，例如 `python3 -m http.server`）。
- 要分享給朋友：`node tools/build.mjs` 產生單一檔案 `dist/index.html`，丟到任何靜態空間（GitHub Pages、Netlify…）就能開。
- 不知道要做什麼？點左下角的「📋 今天」：列出今天重要的事、為什麼重要、在哪裡，可以一鍵出發或跳到下一件事。轉角還差多少錢、線索找到幾條，也會顯示在這裡。
- 電腦：WASD 移動、滑鼠轉頭（點一下畫面鎖定滑鼠，Esc 放開；也可以按住拖曳）、←→ 轉身、E 互動、P 手機、M 地圖、數字鍵選選項。
- 手機：左半邊拖曳＝搖桿移動，右半邊拖曳＝轉頭；點人物或物件直接走過去互動；右下大按鈕互動；右上小地圖點了開大地圖。

## 第一週劇情

**開場是週日下午。** 小沛紅著眼睛問你：「有人把我們的事告訴了 Bloom。你知道是誰，對不對？」然後畫面回到七天前。

- **誰是內鬼：** 週四晚上，有人把小沛的財務數字洩漏給連鎖咖啡 Bloom。每一局的內鬼都不一樣（樂樂、阿修、米拉或安森），每個人都有自己的理由，沒有一個是純粹的壞人。
- **怎麼查：** 對朋友用「觀察」、問好日子的老蔡「最近有看到什麼嗎？」、跟 Vivian 見面時反問、或在對方喝醉時聽他說話。不是每條線索都指向真相。
- **週日：** 小沛會問你是誰。說對了（有證據），她能在房東面前扳回一城；說錯了，被冤枉的人會記住；你也可以替人頂罪，或明知道卻不說。查不到的話，真相會在第二週浮出來。

- **EP01〈今天可以準時下班嗎？〉** Bug #4521、米拉的 regression、小沛的驚喜生日派對（19:00 照常開始）、樂樂對阿修的誤會。
- **EP02〈誰睡在我們家沙發上？〉** 剛分手的樂樂想借住：獨居自己決定、合租要跟室友協商；拒絕的話她會去咖啡廳後台或阿修家，產生新的關係。
- **EP03〈最糟糕的星期五〉** 同一晚：公司 release、轉角 Live、教會愛宴、你的約會、快撐不住的安森。可以委託、協調、放鳥。
- **週末** 房東談判、米拉的澳洲決定、週日下午三點咖啡廳的命運：**續約／搬遷／關門**，三種結局都能繼續玩。週日晚上有「第一週回顧」。

## 第二週劇情

- **EP04〈新的位子〉** Feature Owner 公布。你當上的話，由你分工；阿修當上的話，他怎麼分工，看他記不記得你在課長面前說過什麼。
- **EP05〈誰來扛〉** 客戶現場掉資料，根因是第一週 code review「先 merge 再說」的那個 patch。事故報告上要寫一個名字：你自己、流程、阿修，或推給米拉。如果阿修是 owner，他可能求你一起扛，也可能把責任推給你。
- **週三的老位子** 第一週的結局開始收帳：
  - **續約：** 樂樂想免費借店，因為「我有出錢」。
  - **搬家：** 新地方開出條件。
  - **關門：** Bloom 寄來店長的 offer。你可以出錢跟小沛一起在夜市擺咖啡車。
- **安森說他很好。** 你可以相信他，也可以拆穿他。
- **米拉訂好了機票。** 或者，她開始懷疑自己留下來是不是因為不敢走。
- **週日** 樂樂宣布她生日的 KTV 真心話大冒險，接著是「第二週回顧」。第三週〈秘密的保存期限〉會在之後的更新加入。

## 人性：謊言、誘惑與真心話

- **謊言會被記住，也可能被拆穿。** 說謊（請病假、編理由、否認早就知道）會記在帳上。如果當時有人看到你在別的地方，那個人和被你騙的人碰面時，就可能說溜嘴。被拆穿時可以承認、再圓一個謊，或把責任推給別人；被推責任的人也會發現。手機的人物頁看得到你對每個人說過的謊。
- **誘惑。** 課長問週一的問題是誰發現的：你可以說出米拉的名字，也可以說是自己。課長私下問你怎麼看阿修時，他也被問了同樣的問題。連鎖咖啡 Bloom 想花三萬塊買小沛的底線；陳伯其實也有說不出口的難處。這些選擇的後果，有些要到第二週才會浮出來。
- **酒後真心話。** 在好日子喝到微醺，每個人都會說出平常不說的話：他們真正怎麼看你，還有自己的陰暗面。你可以安靜地聽、坦白自己的謊，或趁機套話。第二天早上，對方會傳訊息問你記不記得。
- **背叛另一半。** 有交往對象還跟別人約會，被看到的話，消息會在朋友之間傳開。
- **第一週回顧** 會告訴你，你是怎樣的人，還有到現在還沒有人知道的事。
